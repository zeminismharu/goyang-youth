# 제레미 7일 실험

내 휴대폰 사용과 알고리즘 노출을 7일 동안 기록하고, **내 예측과 실제를 비교**하는 모바일 웹앱(PWA).

## 원칙
- 모든 기록·캡처는 **휴대폰 브라우저 안(IndexedDB)** 에만 저장. 서버·로그인·외부 전송 없음.
- GitHub에는 **코드만** 올라감. GitHub Pages는 앱 파일을 내려주기만 함.
- 체크인은 **그날 밤에 '오늘'을 기록**. 새벽 4시 전까지는 전날로 칩니다.
- 앱 잠금: Face ID(WebAuthn, 서버 없음) + 4자리 비밀번호(Face ID 실패 시 대체) (앱을 열 때, 1분 넘게 나갔다 돌아올 때). 비밀번호는 해시로만 저장. **기록 자체를 암호화하지는 않음.**
- 디자인: 토스 스타일 참고 (회색 배경 + 흰 카드, 큰 제목, 파란 강조색, 하단 고정 버튼). 토스 로고·이름·전용 폰트는 쓰지 않음.

## 진행 상황
- [x] 1-1 뼈대 · 홈(일차/빠진 날 표시) · PWA · 저장소 · 비밀번호 잠금
- [ ] 1-2 0일차: 예측 입력, 체크리스트, 광고 화면 캡처
- [ ] 1-3 데일리 체크인 (최소 터치)
- [ ] 1-4 백업/복원, 모든 데이터 삭제
- [ ] 2 테이크아웃/인스타 분석 (실제 파일 샘플 받은 뒤)
- [ ] 3 리포트 + 이미지/PDF 저장

## 기술 스택
Vite + React(화면), Dexie(IndexedDB 저장), vite-plugin-pwa(홈 화면 앱), GitHub Actions → GitHub Pages(배포)

## 실행 (컴퓨터에서)
```bash
npm install
npm run dev     # 같은 와이파이의 폰에서도 표시되는 주소로 접속 가능 (단, 홈 화면 앱 설치는 https 배포 주소에서만)
npm run build   # 배포용 파일을 dist/ 에 생성
```

## 배포: Cloudflare
결과물은 `npm run build`로 만든 `dist/` 폴더(정적 파일)뿐입니다. Cloudflare가 GitHub 저장소를 지켜보다가 push될 때마다 자동으로 빌드·배포합니다.

- **Pages로 연결할 때:** 빌드 명령 `npm run build`, 출력 폴더 `dist`
- **Workers로 연결할 때:** 빌드 명령 `npm run build`, 배포 명령 `npx wrangler deploy` (`wrangler.jsonc` 사용)

⚠️ Face ID 등록은 배포 주소(도메인)에 묶입니다. 주소를 바꾸면 Face ID를 다시 켜야 합니다.
